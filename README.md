### Create polished demo videos in minutes
[Reco](https://reco-green.vercel.app/) is your **web-based screen recording editor** for **walkthroughs, demos, product videos**, and more. 

---

## What is Reco?

Reco is a powerful browser-based application for editing screen captures with motion-driven presentation tools built in. Instead of sending raw footage to a motion designer just to add zooms, cursor polish, or a styled background, Reco handles that workflow directly in your browser.

Reco runs entirely on the web, leveraging modern browser APIs for local project persistence and heavy media processing. No desktop installation required!

---

# Core Features

## Auto-zooms, cursor polish, and styled frames
Reco can automatically emphasize activity with zoom suggestions, smooth cursor movement, add motion effects, and place the final composition inside a styled frame with wallpapers, colors, gradients, blur, padding, and shadows.

## Dynamic webcam bubble overlays
Add webcam footage as an overlay bubble, position it with presets or custom coordinates, mirror it, control shadow and roundness, and optionally make it react to zoom so it stays visually balanced during motion.

## Web-Native Timeline editing
Use drag-and-drop timeline tools for zooms, trims, speed regions, annotations, extra audio regions, and crop-aware edits. Everything is processed directly in your browser. Save and reopen work as `.reco` project files securely stored in IndexedDB.

---

## All Features

### Editing & Cloud Storage
- Open existing recordings or import any MP4/WebM video
- Resume editing from saved projects in your browser's local storage
- Sign in securely with Supabase Auth to sync your profile
- Fully private, client-side rendering with no video uploads required

### Timeline Tools
- Drag-and-drop timeline editing
- Trim unwanted sections
- Add manual zoom regions
- Use automatic zoom suggestions based on cursor activity
- Add speed-up and slow-down regions
- Add text, image, and figure annotations
- Crop the recorded frame

### Exporting
- Export compositions as MP4 up to 4K resolution at 60fps
- Export compositions as optimized GIF up to 60fps
- Export single-frame snapshots
- Directly download to your device without leaving the browser
